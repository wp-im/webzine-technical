== Description ==
工程视窗出版工作台：分层标题、工具组、资源目录与顺序面板。
Copyright (C) 2026 wp-im. Licensed under GPL-2.0-or-later.
Theme PHP, CSS, JavaScript and bundled SVG artwork are original project work,
with WordPress integration adapted from the archived project prototypes.
No external fonts or third-party UI framework is bundled. screenshot.png is
an original capture of the local demonstration with project-authored illustrations.

Independent PHP Classic Theme. Configure Appearance > Customize, Menus and Widgets.
Six menu locations, twelve widget areas, and native posts/pages/categories/comments.
No parent theme, build tool or external service is required on the installed site.
Browser-local bookmarks do not synchronize with WordPress user accounts.
