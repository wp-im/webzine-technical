# Webzine Technical

工程视窗出版工作台：分层标题、工具组、资源目录与顺序面板。

An independent, mobile-first WordPress Classic Theme, version 0.1.0. No parent theme or build tool is required at runtime.

## Install and customize

Download `webzine-technical-0.1.0.zip` from this repository's Release, then use Appearance → Themes → Add New → Upload Theme. Configure Appearance → Customize, Menus and Widgets. The theme supports native posts, pages, categories, tags, archives, comments, media and password protection, six menu locations and twelve widget areas. Content and site settings are stored in WordPress, not this repository.

The reading layout, colors, fonts, density, image/list views, featured story, navigation, contents and style-specific settings use the native Customizer. Bookmarks are browser-local and do not synchronize with a WordPress account. JavaScript enhances reading controls; ordinary reading and navigation remain available without it.

## Validation and limits

Tested locally on WordPress 7.1.4, PHP 8.4.27 and SQLite: actual native admin save/reload, nine viewport sizes, 16 public route types at phone/desktop widths, Firefox/WebKit core flows, keyboard navigation, storage failure, comments, repeatable demo import, and installation of this exact theme ZIP. Theme Check reported no REQUIRED/WARNING items. Automated axe scans on the tested home, archive and long article had no reported violations.

These are local results, not production acceptance, WordPress.org review or a claim of complete accessibility compliance. Real devices, real Safari, human screen-reader use and the declared minimum WordPress/PHP versions were not separately tested. Public deployment is tracked independently.
